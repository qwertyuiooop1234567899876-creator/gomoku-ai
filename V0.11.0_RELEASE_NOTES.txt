Gomoku AI V0.11.0
==================

主要改动
--------

1. PVC 与 Arena 观看模式的局面评分条改用独立 YiXin 搜索评价。
2. YiXin 评分统一转换为白棋视角，避免轮到不同颜色时左右颠倒。
3. 显示 YiXin 原始评价、搜索深度和耗时；形势条百分比明确不是胜率。
4. 空棋盘也由 YiXin 评价，不再固定显示 50:50。
5. 同一局面重复刷新使用缓存，不会重复启动分析。
6. YiXin 缺失、超时或没有返回评价时显示“不可用”，不会回退到
   旧启发式分值。
7. 五连、一步必胜、双胜点和平局仍由规则直接判定，优先于模型。
8. run_yixin_cvc.bat 默认开启 YiXin 评价条。

设置
----

yixin_settings.json 新增：

  "evaluation_time_seconds": 2.0

它只控制评分条每个新局面的 YiXin 分析时间，不改变 YiXin 参赛方的
timeout_turn_seconds，也不改变 SearchAI 的搜索参数。

验证
----

  python -m unittest discover -v

预期：

  Ran 188 tests
  OK

兼容性
------

本版本建立在 V0.10.3 上，保留 V0.10.1 分析序列化修复、
V0.10.2 BOARD 身份映射修复及 V0.10.3 TURN 连续同步修复。
