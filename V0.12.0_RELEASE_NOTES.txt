Gomoku AI V0.12.0
==================

主题：Search Core 2 第一阶段——等价战术内核加速

本版本在 V0.11.0 的 PVS、VCF、Defense-VCT、AND/OR ProofSearch、
100,000 条独立 TT 和 YiXin 评分条基础上，优化每个搜索节点最常调用的
局部战术计算。搜索深度、候选数量、评分常量和强制胜负语义均未改变。

主要改动
--------

1. 一步胜点改为不落子的连续线判断
   - 不再为棋盘上每个空点执行 place/check_win/undo。
   - 横、竖和两条斜线直接检查该点两侧连续棋子。

2. 威胁画像改为四条九格局部线计算
   - 活三、冲四、活四、双四、四三和双活三保持原定义。
   - 不再为每个候选反复临时落子、撤销和更新 Zobrist。

3. 候选棋型增益改为四条受影响整线的精确差分
   - 一手棋只可能改变穿过该点的四条线。
   - 不再为每个候选、双方各扫描一次完整棋盘。

4. 静态线评分增加纯函数缓存
   - 相同棋盘线的棋型分可安全复用。
   - 不共享搜索结果，不改变黑白 SearchAI 的独立 TT。

5. 增加固定局面性能回归
   - search_benchmark.py
   - run_search_benchmark.bat
   - 覆盖 J9、G9、H11 和 I4 四类真实回归局面。
   - 每次同时验证预期着法和搜索后棋盘完整恢复。

6. 增加差分等价测试
   - 新内核与 V0.11.0 的模拟落子参考算法逐项比较。
   - 覆盖威胁画像、候选评分和一步胜点。

实测摘要
--------

同一环境、同一固定局面、每项运行 3 次取中位数：

- J9 普通反击：0.469s -> 0.114s，4.11x
- G9 多重威胁：0.619s -> 0.174s，3.56x
- H11 Defense-VCT：2.425s -> 0.825s，2.94x
- I4 Proof 风险：1.883s -> 1.549s，1.22x
- 四项中位数合计：5.395s -> 2.662s，整体 2.03x

四项预期着法、完成深度及 PVS 节点数均保持一致。I4 的限时证明切片
在更短时间内从约 22 个 Proof 节点提升到 124 个，仍选择 J5。

未包含的改动
------------

- 未实现 DF-PN；保留现有 AND/OR ProofSearch。
- 未改 SearchAI 评分权重、候选数量、PVS/VCF/TT 策略。
- 未改 YiXin 核心、线程、思考时间或评分条协议。
- 未加入 MCTS、神经网络或 YiXin 辅助选棋。
