Gomoku AI V0.17.1 Dynamic Pair Attempt Audit
==============================================

目标与边界
----------
- 本版是纯诊断补丁，不改变候选生成、搜索、评分、预算、调度、仲裁、
  Proof、VCF 或最终选着语义。
- 修复动态 pair 调用返回 `None` 时的审计盲区：此前着法已进入
  `entered_moves`，却既不出现在成功 pair 记录里，也不会被列为未配对。

逐次尝试审计
------------
- 每次实际进入动态 pair 搜索时记录通道、当前 leader、challenger、请求
  预算、真实耗时、完成深度、节点数和结果状态。
- 普通动态复核、主动反击安全通道、边界战术升级和边界次级通道使用
  独立的 channel 名称，后续可以直接比较各通道的预算兑现率。
- 未完成任何完整深度的调用显式记录为 `no_completed_layer`；正常返回的
  调用记录为 `result_available`，不再依赖成功 pair trace 反推失败尝试。
- JSON 始终保存触发过的尝试；TXT 仅写紧凑的总数和状态计数，控制记录
  体积，同时让人工复盘能一眼看到失败调用。

验证
----
- 新增回归覆盖：`None` 结果仍可序列化、成功结果保留通道/深度/节点，
  新一手搜索会清空上一手的尝试记录。
- 全量 473 项测试通过。

Native Phase 2 边界
-------------------
- V0.17.1 不接入 Native 生产搜索。预检确认现有 C++ Phase 1 等价于关闭
  安静前沿扩展的主树语义，而实际普通动态 pair 会开启安静前沿扩展。
- 在补齐明确的扩展策略 ABI 与等价门禁前，禁止用现有 Native 固定深度
  结果替换生产动态 pair，避免以提速名义偷换搜索算法。

记录边界
--------
- 不恢复、生成或提交 `records/` 中的历史、本机对局或分析文件。
